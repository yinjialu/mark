# 使用 mark

## 保存文字

选中 Codex 回复中值得保留的一段话 → 点原生浮栏 **mark** → 出现 **✓ mark**。取消选区后，已保存文字下方会显示金色下划线。保存动作不发送消息。

## 保存图片、图表和表格

图片旁、Mermaid 图表的展开/复制控件后面、表格复制控件后面有书签按钮。点击保存完整块内容和来源位置。图片保存为静态 PNG；动态图不会保留动画。表格保存结构化行列；Mermaid 保存可安全查看的 SVG 快照。

## 在当前任务中回看

右侧每条短横线对应一处 mark。移动鼠标，横线及相邻横线一起展开，显示内容预览；点击跳到标记位置。右侧不再重复放置收藏库图标，统一使用左侧 **mark** 入口。

## 跨任务寻找

左侧 **mark** 打开内置收藏页面。使用“全部 / 当前任务 / 回收站”切换范围；“当前任务”仅在有来源任务时显示。标签切换复用 Codex 原生组件，支持方向键、Home/End 和焦点跟随。搜索原文、来源任务、标签或备注；空格分隔的关键词需同时匹配，这是字面搜索。点击一条收藏可查看保存时的上下文和高亮，点击 **定位原文** 返回来源任务。

原文未变化时定位选区；匹配失效时退到对应消息，或提示查看已保存快照。保存快照不等于最新原文。页面中的“标题、标签与备注”可展开编辑，删除的收藏可以在回收站恢复。

## 数据备份

默认位置：`~/.local/share/codex-marks/`。同时备份 `marks.sqlite3` 和 `assets/`；JSON/Markdown 导出不包含图片资产。迁移前退出使用收藏库的客户端。收藏不会随插件卸载自动删除。

## 卸载

退出副本并打开正式 Codex 后，可删除 `~/Applications/mark.app` 和 `~/Library/Application Support/mark/`。这会移除启动器和全部副本，也会失去副本回退能力。保留 `~/.local/share/codex-marks/` 就能保留收藏。

如果安装过可选插件，使用 `codex plugin remove codex-marks@mark` 移除。旧菜单栏 companion 已退役，无需安装。
