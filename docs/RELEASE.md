# v0.1.0-preview.12

- README 使用用户授权的实际客户端截图，展示表格和 Mermaid 图表收藏。

- 安装指令不再固定旧标签：查询 GitHub 公开发布列表，自动选择最新兼容版本。
- 收藏页新增“检查更新”和“安装并重启”，打开时每天最多自动检查一次，离线不影响使用。
- 更新包校验通过后才执行安装；升级失败恢复旧启动器和版本状态，保留收藏与旧副本。
- 成功升级或回退后，Dock 中已有的 mark 入口自动指向当前副本，合并重复副本入口；保留其他应用和用户取消固定的选择。
- 客户端副本名称统一为 ChatGPT mark，便于在 Dock 中与正式版区分。
- 启动器改为原生 arm64 可执行程序，修复打开 mark 时出现 Rosetta 安装提示的问题。
- 右侧导航复用左侧的 150 毫秒 hover 预加载和轮次定位，随后细定位到 mark；快速划过不加载。
- 右侧导航接入原生消息定位，支持先展开或加载原消息，再定位标记。
- 找不到原文时保留当前任务并提示重试，不再自动跳到收藏页。
- 原文定位上移：标记顶部对齐内容区高度的 15%，减少大图上方空白。
- 修复右侧导航首次 hover 时预览偶尔出现在左上角；定位目标失效时关闭预览，避免遗留卡片。
- 标记表格四周增加内边距：上下 8px，左右 12px；取消 mark 后恢复原布局。
- 修复表格 mark 上下边框被滚动容器裁切：边框向表格内侧绘制，保留横向滚动。
- 文字、图片、Mermaid 和表格按钮支持再次点击取消 mark。
- 重新选中同一处文字识别已标记状态；按任务、消息、内容哈希和精确选区匹配，避免误取消重复文字。
- 取消清除下划线或边框，并同步收藏库和右侧导航；收藏移入回收站，可以恢复。
- 保持 Codex 原生 Mermaid 展开按钮的显示规则。

仅支持 macOS Apple Silicon、Codex 26.901.51231 / build 8109 和匹配的原始包哈希。安装器在本机生成独立副本，不包含客户端或个人数据。旧版需按新安装说明升级一次，此后可在 mark 页面检查更新；旧副本保留供回退。

此版本仍为开发者预览：包含自动测试和开发机构建、签名及进程存活检查；第二台 Mac 首装、系统信任提示和全部真实交互需另行验收。
