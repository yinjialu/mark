# mark v0.1.1

mark v0.1.1 适配升级后的 ChatGPT 桌面客户端，同时保留上一版客户端支持。

## 新版客户端适配

- 新增 ChatGPT 26.908.40834 / build 8881 的精确适配器。
- 重新定位选择浮栏、图片、Mermaid、表格、左侧入口、收藏页和右侧导航对应的新版资源结构。
- 原有 26.901.51231 / build 8109 适配器继续保留，方便旧客户端和回退副本使用。
- 正式应用仍保持原样；安装器从正式应用生成并本地签名独立的 ChatGPT mark 副本。

## 更清楚的收藏页

- 复用 Codex 原生页面、搜索、Tabs、输入框和按钮，收紧双栏间距与预览留白。
- 打开后自动选择一条收藏；列表展示类型、来源和标签，表格与图表使用可读摘要。
- 文字先展示收藏片段，支持切换完整上下文；“定位原文”和复制放到详情顶部。
- 编辑时提示未保存，保存后展示备注；保留回收站、恢复和深浅主题。

## 标记、回看和安装

- 原生浮栏标记文字；图片、图表和表格使用书签按钮，再点一次取消。
- 右侧导航悬停预览，点击加载来源消息并定位标记；未找到时保留当前任务。
- GitHub 安装脚本自动选择最新兼容版本，显示进度并校验发布包。
- 收藏页支持检查更新和手动安装重启，失败保留旧副本与收藏。
- 日常使用统一的 ChatGPT mark Dock 入口，原始客户端保留供升级。

## 安装与升级

阅读 [安装说明](https://github.com/yinjialu/mark/blob/v0.1.1/docs/INSTALL.md)，将其中的指令复制给 Codex，或使用终端安装脚本。也可下载 ZIP，解压后双击 `Install.command`。

preview.12 用户可在 mark 页面检查更新；preview.11 及更早版本需运行新的 GitHub 安装流程升级一次。无需迁移收藏数据。

## 支持范围与验证边界

仅支持 **macOS Apple Silicon、ChatGPT 26.908.40834 / build 8881 或 26.901.51231 / build 8109** 及清单匹配的原始包哈希。未知版本停止安装，不会绕过兼容性检查。包内只含本项目源码、文档与示例资产，不分发客户端或个人收藏数据。

本项目不是 OpenAI 官方插件。安装时生成本地签名的独立副本，仅副本启用 `disable-library-validation`；没有 Developer ID 签名或 Apple 公证。第二台 Mac 首装、系统信任提示以及所有真实客户端交互尚未完成本版验收。发布编号结束预览，不代表扩展了支持范围。

本版验证包含 Python/Node 回归、对 build 8881 的 12 个目标资源替换、9,138 个未修改 ASAR 条目逐项哈希核对、正式应用签名验证、独立副本深度签名与版本探针，以及独立用户数据目录的真实启动检查。真实启动已完成主窗口与 app-server 加载；发布前未切换开发者正在使用的正式客户端，仍需在日常用户环境中完成按钮、保存与来源定位点击验收。
