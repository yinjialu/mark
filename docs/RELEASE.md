# v0.1.0-preview.1

首个公开的 macOS Apple Silicon 开发者预览包。

- 原生划词 mark、文字下划线、图片/图表/表格收藏。
- 左侧 mark 页面，复用原生 Tabs 的选中、悬停与键盘切换；右侧连续波动导航，移除重复的收藏库图标。
- 精确版本检查、本机生成副本、本地签名、升级检查和上一版回退。
- 在 Codex 内安装时可使用 `launch --switch --detached`，8 秒后切换并保存结果。
- Git clone 与发布 ZIP 共用校验流程；仅忽略 Git 元数据及 Python 缓存等非包内容。

仅支持 Codex 26.901.51231 / build 8109 / arm64 和匹配的原始包哈希。源码包不含 Codex 客户端或个人数据。详见 README 与安装说明。

验证范围：安装器自动测试、原生组件独立测试，以及开发机上的副本构建与签名/进程存活检查。第二台 Mac 首装、系统信任提示和所有真实交互不在自动检查保证范围内。开发过程中曾观察到一次客户端退出并成功回退；当时日志记录系统退出请求，原因未确证。出现类似情况请保留错误摘要，勿关闭系统安全检查。
