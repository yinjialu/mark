# mark v0.1.6

mark v0.1.6 修复右侧导航偶尔只能回到消息附近、无法落到具体文字选区或图表的问题。

## 精确定位

- 消息容器出现后，继续等待具体文字选区、图片、Mermaid 图表或表格完成挂载。
- 对应轮次存在时先复用原生轮次导航；没有 turn ID 的收藏继续使用保存的消息 ID 加载原文。
- 兼容新版任务历史文件名，在读取旧收藏时补全缺失的 turn ID 和轮次标题。
- 先把已找到的消息带入可见区域，触发其中延迟渲染的内容，再滚动到准确标记。
- 只有在原文变化或精确目标无法验证时，才退到对应消息或轮次。

## 回归验证

- 增加“消息已出现、具体 Mermaid block 稍后挂载”的导航测试。
- 增加带 turn 后缀的历史文件识别和旧收藏运行时补全测试。
- Python 47 项测试通过，Node 8 项测试通过。
- 当前支持的 ChatGPT build 8881 实际注入包通过完整性和签名检查。

## 安装与升级

阅读 [安装说明](https://github.com/yinjialu/mark/blob/v0.1.6/docs/INSTALL.md)，将其中的指令复制给 Codex，或使用终端安装脚本。也可下载 ZIP，解压后双击 `Install.command`。

v0.1.5 用户可在 mark 页面检查更新并安装 v0.1.6。无需迁移收藏数据。

## 支持范围与验证边界

支持范围与 v0.1.5 相同：**macOS Apple Silicon、ChatGPT 26.908.40834 / build 8881 或 26.901.51231 / build 8109**，并要求清单精确匹配原始包哈希。未知版本停止安装，保留上一可用副本。

收藏数据库 `~/.local/share/codex-marks/marks.sqlite3` 及其 `assets/` 不会被迁移或清理。
